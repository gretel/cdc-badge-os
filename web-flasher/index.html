Enter Bootloader Mode

On the back of the badge, locate the FLASH and RESET buttons.

  1. Press and hold FLASH
  2. While holding FLASH, press RESET once and release it
  3. Release FLASH
  4. After flashing, press RESET once to start the new firmware
! The display will not react and the device will appear to be turned off. This is expected — the badge is now in bootloader mode.

Connect the badge via USB, enter bootloader mode, then click the button below.

Your browser does not support Web Serial.
Please use Google Chrome or Microsoft Edge (desktop).
Serial access was denied. Please grant permission and try again.

Requirements

  • Google Chrome or Microsoft Edge (version 89+)
  • USB cable (data-capable, not charge-only)
  • Badge in bootloader mode (see steps above)
